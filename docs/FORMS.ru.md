# Формы, доступные подписи и проверка данных

`Form` даёт текстовым полям одну серверную цепочку проверки и отправки.
`FormField` связывает редактор, нативный `Label`, подсказку и сообщения об
ошибках. Подойдут `InputField`, `PasswordInput`, `SuggestionField` и
`TextArea`. Форма показана в [галерее](WIDGET_GALLERY.ru.md#form).

```java
Form form = new Form("Заявка", "Отправить");
FormField title = new FormField("title", "Название учебного предмета");
FormField check = new FormField("check", "Повторите название");
title.setRequired(true);
title.setMaxLength(40);
title.setAutocomplete("off");
title.setHelp("Укажите до 40 символов.");
form.addField(title);
form.addField(check);

form.setValidator(values -> values.get("title").equals(values.get("check"))
    ? Form.Result.success()
    : new Form.Result(Map.of("check", "Названия не совпадают."), ""));
form.onSubmit(values -> demoService.submit(values));
root.add(form);
```

Обработчик `onSubmit` принимает неизменяемый снимок и быстро возвращает
`CompletionStage<Form.Result>`. Он не должен ждать сеть в потоке страницы.
Настройте `Form.Messages` и `FormField.setConstraintMessages` для языка
приложения. Детали исключений не передаются пользователю.

- Значение читается из текущей реактивной модели редактора
  (`getEditor().setTextModel(...)`). `isDirty()` сравнивает его с сохранённой
  исходной точкой; `isTouched()` отмечается после blur или проверки формы.
  Успех сохраняет новую исходную точку, только если пользователь ещё не
  отредактировал снимок. `markPristine()` позволяет выставить её вручную.
- Обязательность, лимит длины в UTF-16 и валидность модели проверяются на
  сервере перед межполевой проверкой. Нативные атрибуты помогают браузеру, но
  не заменяют проверку. Скрытые, недоступные и вынутые из формы поля не
  участвуют. Поле только для чтения участвует как значение, но не редактируется.
- Ошибки полей адресованы стабильным именам, сообщение всей формы передаётся
  отдельно. Порядок полей задаёт первый фокус ошибки. Виджет ошибки не заменяет
  модель значения, а `aria-describedby` включает подсказку и текущую ошибку.
  Подпись фокусирует редактор нативно, в том числе при нажатии мышью.
- `Enter` и кнопка используют общую отправку через [R44](KEYBOARD_SHORTCUTS.ru.md),
  без HTTP-формы или второго канала. При упаковке однострочного поля
  `FormField` назначает его немодифицированный `onEnter`; другие клавишные
  подписки остаются приложению. `TextArea` сохраняет перевод строки,
  `SuggestionField` выбирает вариант, IME завершает композицию без отправки.
- Вместо накопления повторных действий на время ожидания устанавливается
  `aria-busy`, кнопка отключается, а сервер игнорирует независимые повторные
  попытки. Ошибка не сбрасывает ввод; если он уже изменён, запоздавшие ошибки
  отдельных полей не переносятся на новые значения. Закрытая страница не
  получает результат от предыдущего запроса.

AllWidgets показывает локальную учебную форму: повторите «Бумага» для успеха
или «Занято» для имитации отказа. Эти данные не используются в настоящем сервисе.
В интеграционных тестах сенсорный ввод эмулируется, а IME представлен событиями
композиции; это не проверка физического мобильного устройства или реального IME.
