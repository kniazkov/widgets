# Обновление и эксплуатация приложения Widgets

[Web Widgets](../../README.ru.md) · [English](../en/operations.md)

## Обновление и откат

Зафиксируй одну версию для всех Maven-модулей Widgets. До 1.0 смена минорной версии может нарушить совместимость. Прочитай [список изменений](../../CHANGELOG.md), пересобери приложение и проверь `mvn dependency:tree`. Для перехода с исторической версии 0.1 нужна перекомпиляция, поскольку под этим номером выходили разные сборки.

Проверь собранное приложение на тестовом сервере. Открой страницу, отправь форму и попробуй загрузить файл, если приложение принимает файлы. Разворачивай один и тот же JAR вместе с его браузерными ресурсами. По идентификатору сборки браузер обнаруживает устаревшие ресурсы. Сохрани предыдущий артефакт приложения и резервную копию данных. Перед откатом проверь совместимость схемы. Миграциями базы управляет приложение.

## Что происходит при обрыве связи

При кратком обрыве браузер повторяет запросы. Пока страница жива на сервере, черновик и история сохраняются. Повторное событие сервер может подтвердить без второго вызова обработчика. Для внешних операций, например списания денег, приложению нужны собственные ключи идемпотентности.

При перезапуске сервера страницы в памяти, сессии и ожидающие события теряются. Браузер открывает новую страницу по тому же URL. Перед развёртыванием сохраняй важные черновики в постоянное хранилище. Если экземпляров приложения несколько, направляй запросы живой сессии её владельцу. Другой экземпляр не сможет продолжить работу с её деревом виджетов.

## Ограничения загрузки файлов

По умолчанию один файл может занимать до 128 МиБ. Widgets передаёт его частями по 64 КиБ. Лимиты файла и части задаются отдельно через `Options.Builder.setMaxFileSize` и `setChunkSize`. Максимальный размер части — 1 МиБ. В лимите запроса на прокси оставь место для заголовков multipart.

По умолчанию реестр допускает 16 незавершённых файлов на клиента, 64 на приложение и до 256 МиБ суммарного заявленного размера. В срок 300 секунд входит и обработка файла. Если содержимое понадобится после завершения обработчика, скопируй его в хранилище приложения. [Виджеты загрузки](widgets/files.md)
