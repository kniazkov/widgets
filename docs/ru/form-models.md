# Форма с проверкой и сохранением

[MVC на примере счётчика](mvc-counter.md) · [English](../en/form-models.md)

Сделаем форму для добавочного номера телефона. Пока ты печатаешь, форма проверяет ввод.
Даже когда все четыре цифры введены верно, строка **Saved extension** остаётся прежней.
Она изменится, когда ты нажмёшь **Save** или Enter.

## Запусти форму

1. Открой Maven-проект из [быстрого старта](quick-start.md). Если счётчик запущен, останови его сочетанием Ctrl+C.
2. Сохрани [ExtensionForm.java](../examples/ExtensionForm.java) в `src/main/java/example/ExtensionForm.java`.
3. В `pom.xml` замени `example.Counter` на `example.ExtensionForm` внутри `<mainClass>`.
4. Выполни `mvn compile exec:java` и открой [localhost:8080](http://localhost:8080/).

Проделай эти действия по порядку. Подсказка **Enter exactly 4 digits (0–9).** объясняет, как исправить ввод.

| Действие | Подсказка | Кнопка Save | Сохранённый номер |
| --- | --- | --- | --- |
| Открой форму с пустым полем | Видна | Недоступна | Пусто |
| Введи `12a4` | Видна | Недоступна | Пусто |
| Замени текст на `0042` | Скрыта | Доступна | Пусто |
| Нажми **Save** | Скрыта | Доступна | `0042` |
| Очисти поле и нажми Enter | Видна | Недоступна | `0042` |
| Введи `1234` и нажми Enter | Скрыта | Доступна | `1234` |

## Где живёт введённый текст

Поле и строка результата привязаны к разным моделям. `input.setTextModel(draft)` связывает
поле с черновиком в обе стороны. Ввод в браузере обновляет `draft` на сервере, а вызов
`draft.setData("0042")` из Java показал бы эти цифры в поле. Строка результата привязана
к `saved` через `value.setTextModel(saved)`. Поэтому при редактировании она сохраняет
предыдущий номер.

`ExtensionModel` наследует хранение строки и уведомления об изменениях от
`DefaultModel<String>`. Номер хранится как текст, чтобы сохранить начальные нули.
Правило задаёт метод `isValid()`.

```java
@Override
public boolean isValid() {
    return FORMAT.matcher(getData()).matches();
}
```

`getData()` возвращает текущий текст, даже если это `12a4`. Шаблон `FORMAT` проверяет,
состоит ли вся строка ровно из четырёх цифр от 0 до 9. Вызов `draft.getValidFlagModel()`
даёт **производную модель**. Её значение следует за результатом проверки при каждом
изменении черновика. Когда номер верный, `error.setHiddenStateModel(valid)` скрывает
подсказку. Кнопка использует обратный флаг `valid.invert()`, поэтому остаётся недоступной,
пока в поле ошибка.

## Когда номер сохранён

Контроллер кнопки — лямбда, зарегистрированная через `onClick`. Действие вынесено в обычный
Java-метод, поэтому его можно вызвать и по нажатию Enter в поле.

```java
button.onClick(event -> save(draft, saved));
input.onEnter(event -> save(draft, saved));
```

Оба обработчика проверяют черновик в одном месте на сервере.

```java
private static void save(ExtensionModel draft, StringModel saved) {
    if (draft.isValid()) {
        saved.setData(draft.getData());
    }
}
```

Момент сохранения — вызов `saved.setData(...)`. Он копирует проверенный номер и уведомляет
привязанную надпись. В примере обе модели живут в памяти одного экземпляра страницы.
Если номер должен пережить перезапуск приложения, запиши его в хранилище в этом обработчике
и обнови `saved` после успешной записи.

**Попробуй изменить правило.** Поменяй `DIGITS` с `4` на `5`, перезапусти приложение и
открой форму снова. Теперь подсказка просит пять цифр. После ввода `0042` кнопка ещё
недоступна. Введи `00042` и нажми **Save** — строка результата покажет все пять цифр.
