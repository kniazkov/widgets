# SplitPane

SplitPane делит пространство между двумя блочными виджетами. Положение разделителя — целое число процентов, отведённых первой области. Ширина самого разделителя исключается из расчёта.

```java
IntegerModel position = new IntegerModel(38);
SplitPane editor = new SplitPane(
    SplitPane.Axis.HORIZONTAL, "Размер списка коллекций",
    20, 75, position, catalog, details);
editor.setHeight(300);
root.add(editor);
```

В этом примере каталог занимает 38 % доступной ширины. Его можно увеличить до 75 % или уменьшить до 20 %. Границы задаются при создании и должны удовлетворять условию `0 ≤ minimum < maximum ≤ 100`. Деление `VERTICAL` располагает области сверху вниз. Для вложенного редактора в качестве любой области передай другой SplitPane.

**Клавиатура и жесты.** Tab переводит фокус на разделитель. Стрелки вдоль оси изменяют размер на один процентный пункт, Shift со стрелкой — на десять. Home и End устанавливают нижнюю и верхнюю границы. Имя разделителя в конструкторе должно обозначать регулируемую область. Браузер сообщает её текущее значение, границы и ориентацию разделителя через ARIA.

Перетаскивание мышью или касанием сразу меняет размеры на экране. Модель обновляется при отпускании. Отмена жеста, потеря захвата или удаление виджета отменяют предварительное изменение.

**Размер контейнера.** При ширине контейнера меньше 480 CSS-пикселей горизонтальная пара становится вертикальной. Процент сохраняется, а клавиатура переключается на стрелки вверх и вниз. Граница определяется отдельно для каждого вложенного контейнера. По умолчанию высота равна 16 rem. Для редактора с ограниченной высотой её можно задать через `setHeight`. Содержимое, превышающее размер области, прокручивается.

**Модель приложения.** Передай ту же `Model<Integer>` при повторном создании виджета, чтобы восстановить положение. Для сохранения между сессиями приложение самостоятельно записывает значение в свои настройки. Вызов `editor.setPosition(50)` применяет границы и записывает значение в модель. Изменение непосредственно через `position.setData(...)` обновляет экран. Если внешняя модель содержит значение вне диапазона, виджет показывает ближайшую границу, сохраняя исходное значение модели. После `dispose()` виджет снимает подписку.

**Содержимое.** Первая и вторая области следуют порядку дочерних виджетов. После удаления одного ребёнка оставшийся занимает всю область, разделитель скрывается. Новый ребёнок добавляется в конец. Третий ребёнок вызывает исключение.
