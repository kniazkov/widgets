# Проверка R27: NumberField и QuantityField

16 ноября 2026 года. База: `a53086ad856eeb8b7f621196275de834999125da` (master после PR #177).
Ветка: `feat/number-quantity-fields`. Точный commit и результаты проверки дерева
указаны в PR.

Съёмка выполнена на реализации `65f421a6834312c84533b528b2e3ff02630a3a41`.
Дополнение к PR меняет только документацию и изображения; Java/JS/CSS реализации

## Среда и результаты

Облачный Debian 13, Temurin 21.0.13, Maven 3.9.9, Node.js 24.22.1,
Playwright 1.62.1. package-lock.json неизменён. Maven использует предварительно
загруженный кэш (`-o`). Дополнительные библиотеки WebKit распакованы из
официальных Debian-пакетов и доступны через LD_LIBRARY_PATH.
`PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1` отключает проверку ldconfig,
который не видит локальные библиотеки; реальные Chromium/WebKit запускаются.

- `mvn -o verify`: **625 Java-тестов**, ошибок/пропусков нет, Checkstyle — 0.
  Собраны JAR, sources и JavaDoc. Существующие предупреждения JavaDoc остаются.
- `npm run test:js`: **249/249**.
- `npm run test:browser`: **успешно**, включая ESLint/Prettier, галерею
  **59 классов / 78 изображений**, **249 JS-тестов и 220 E2E** в Chromium/WebKit.
  Это полный повтор после добавления снимков на окончательном коде реализации.
- `node scripts/run-e2e.mjs numbers.spec.js`: **4/4**, Chromium/WebKit,
  desktop 1280 и mobile 390 CSS px. На окончательном дереве повтор: **4/4**, 25,7 с.
- Полный `npm run test:e2e`: **220/220**, выполнен отдельно, чтобы ошибка
  галереи не скрыла функциональные регрессии.

Первый полный E2E был начат до перепривязки disabled/read-only моделей;
после неё прошли Java verify и четыре целевых E2E. Повторный полный browser gate
после съёмки проверяет окончательную реализацию вместе с галереей.

## Сценарии

Java: точные числа выше 2^53 и Long.MAX_VALUE, отсутствие переполнения/округления,
лимиты precision/scale/длины, неверные и незавершённые строки, null,
отклонение неверного типа JSON payload и превышенного input limit. Проверены
включительные границы, смещённая сетка шага, off-grid максимум, атомарный отказ
неверной конфигурации, пустота, локаль ru/en и запрет переинтерпретации неверного
ввода при смене локали, независимая копия модели, общий редактор модели.

QuantityField: обязательность/ошибки Form, серверный отказ до обработчика,
единый путь +/- через модель, обновление ограничений, замена disabled-модели,
read-only, повторная проверка даже при прямом вызове старого controller,
снятие подписок при dispose.

E2E: точная строка `9007199254740993,01` даёт серверный результат
`9007199254740993.01`; промежуточные `-`, `-,`, `12,` сохраняются. Проверены
compositionstart/end и подавление Enter во время IME, inputType=insertFromPaste,
отсутствие прыжка каретки после серверного ответа, дробный шаг, границы,
изменение лимита без исправления введённого числа, Enter/Space/tap, удержание
Space без автоповтора, disabled и read-only. Axe проверяет новые редакторы.

Начальные E2E выявили контраст 4.41:1 в ошибочном состоянии NumberField:
цвет текста затемнён до #991b1b; после исправления целевые тесты прошли.

## Облачная ручная проверка и снимки

Повторная проверка выяснила причину прежнего отказа: скрипт запуска AllWidgets
не имел права исполнения и завершался с Permission denied. Вкладка оказывалась
на служебном `chrome-error://`, обновление которого блокирует инструмент.
Скрипт запущен через bash; обычный HTTP-адрес AllWidgets успешно открыт.

В живом облачном Chromium проверены точное число `9007199254740993,01` и результат
сервера `9007199254740993.01`, Enter в редакторе и на кнопке увеличения, максимум 2,
сохранение неверного ввода `12,`, отдельные ошибки преобразования и лимита,
блокировка кнопок, исправление и успешная повторная отправка. На ширине iframe
390 CSS px проверены перенос кнопок, читаемость длинного числа и отправка Enter
с количеством 3. Touch проверен автоматическими тестами; физические Android/iOS
и ручное прослушивание screen reader не проверялись.

Три PNG вырезаны из реальных скриншотов без изменения масштаба/ретуши:

- `numbers-desktop.png`: normal, точное число, успешная отправка, disabled/read-only;
- `numbers-error.png`: незавершённая дробь, новый максимум и ошибки FormField;
- `numbers-mobile.png`: компоновка при ширине iframe 390 CSS px.

Исходные размеры, координаты вырезок, SHA-256 PNG, commit реализации и SHA-256
AllWidgets сохранены в [manifest.json](images/widgets/manifest.json).
Снимки включены в [галерею](WIDGET_GALLERY.ru.md#numbers) и связаны с
[документацией API](NUMBER_FIELDS.ru.md). Блокер ручной проверки устранён.
