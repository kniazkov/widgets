# Menu, Popover и Tooltip

Три виджета с привязкой к элементу. Пример — карточка «Меню и подсказки у элемента»
в AllWidgets. Реальные изображения находятся в [галерее](WIDGET_GALLERY.ru.md).

## Использование

```java
Button actions = new Button("Действия");
Menu menu = new Menu(actions, "Действия с изделием", List.of(
    new Menu.Item("edit", "Редактировать", true, () -> editProduct()),
    new Menu.Item("delete", "Удалить", false, () -> deleteProduct())
));
Button settings = new Button("Настройки");
Popover popover = new Popover(settings, "Настройки доставки");
InputField note = new InputField("");
note.setAccessibleName("Комментарий");
popover.addBody(new Section(note));
Button help = new Button("Срок изготовления");
Tooltip tooltip = new Tooltip(help, "Точную дату согласуем перед оплатой.");
tooltip.setHoverDelays(400, 120);
root.add(new Section(actions, settings, help));
root.add(menu);
root.add(popover);
root.add(tooltip);
```

Якорь — несобственная ссылка: уничтожение overlay не уничтожает кнопку.
Сам overlay нужно добавить в дерево той же страницы; внутри Dialog оба элемента
нужно добавить в содержимое этого Dialog. Один интерактивный overlay на кнопку.
Не назначайте кнопке одновременно самостоятельное действие, которое меняет страницу:
клик по ней предназначен для открытия/закрытия. Содержимое Popover добавляется через
`addBody`, внутренний контейнер нельзя заменять через унаследованные операции Panel.

Общие методы: `open()`, `close()`, `isOpen()`, `getAnchor()`,
`setPlacement(AnchoredOverlay.Placement.TOP)` и `getPlacement()`.
Предпочтительная сторона по умолчанию — BOTTOM; также есть TOP, LEFT и RIGHT.
`open()` возвращает false, если состояние уже открыто или якорь недоступен на сервере.
Клиент дополнительно проверяет видимость, перекрытие модальным окном и пересечение
с viewport/прокручиваемыми предками. Поэтому серверное `isOpen()` отражает разрешение
на открытие, а не синхронную гарантию видимости пикселей.

## Menu

Плоское меню действий, до 256 пунктов. Ключ непустой, уникальный, до 128 символов;
подпись непустая. `setItems` проверяет всю конфигурацию до замены;
`getItems()` возвращает неизменяемый список. Выключенный пункт виден, но недоступен.
Пустой список допустим. Подменю, разделители и поиск по начальным буквам пока не входят
в контракт. Для переходов используйте обычные Link; Menu предназначено для действий.

Стрелки вверх/вниз на кнопке открывают меню и выбирают последний/первый доступный пункт.
Внутри стрелки циклически перемещают фокус, Home/End выбирают края; disabled пропускаются.
Enter/Space запускают действие. Tab закрывает меню и продолжает обычный порядок страницы
от кнопки. Escape закрывает с возвратом фокуса. Выбор закрывает меню **перед** callback.

Событие содержит поколение конфигурации. Сервер проверяет поколение, открытое состояние,
доступность якоря и выбранного пункта. Повторное/устаревшее событие не запускает callback
повторно; замена списка инвалидирует старые команды. Это защита UI от повторного выбора,
не транзакционная идемпотентность внешнего сервиса или нового открытия меню.
Служебное закрытие с актуальным поколением разрешено и после скрытия контейнера:
оно очищает состояние, но не позволяет выполнить действие скрытого пункта.

## Popover

Именованная немодальная панель (`role=dialog`, без `aria-modal`). Может содержать поля
и кнопки. При открытии фокус получает первый доступный элемент, при Escape или явном
закрытии — якорь. Внешний клик/переход фокуса закрывает панель, сохраняя внешний фокус.
Tab не заперт внутри. Закрытое содержимое исключено из серверной обработки событий;
оно сохраняется, поэтому введённый черновик остаётся до следующего открытия.

## Tooltip

Текстовая подсказка (`role=tooltip`), без интерактивных дочерних элементов.
`setText` обновляет текст. Наведение открывает через 400 мс, уход закрывает через 120 мс;
`setHoverDelays(show, hide)` принимает 0..5000 мс. Фокус открывает без hover-задержки.
Переход указателя на подсказку сохраняет её видимость. Escape закрывает, не двигая фокус;
повторное открытие возможно после ухода указателя/фокуса. Быстрый уход отменяет таймер.
Touch-наведение не открывает подсказку: существенные инструкции и действия должны быть
доступны в обычном интерфейсе или Popover.

`aria-describedby` дополняет существующее описание и ошибку поля, не заменяет их.
Текст доступен как описание и при визуально закрытой подсказке. Уничтожение/отсоединение
снимает только собственную связь, обработчики и таймеры. Якорь может быть любым Widget,
но для клавиатуры он должен сам быть фокусируемым; Tooltip не меняет его tabIndex.

## Размещение, стек и совместимость

Используется нативный **Popover API** в manual-режиме: top layer не обрезается `overflow`
и не получает систему координат предка с `transform`. DOM не переносится, принадлежность
серверному дереву и Dialog сохраняется. Нужен современный браузер с `showPopover`,
ResizeObserver и AbortController; отдельного fallback для старых браузеров нет.
Java и упакованные JS/CSS следует обновлять вместе.

Если места на предпочтительной стороне недостаточно, выбирается противоположная с большим
пространством, затем координаты сдвигаются внутрь visual viewport с отступом 8 px.
Большое содержимое получает внутреннюю прокрутку. Позиция обновляется при scroll, resize,
изменении размеров содержимого/якоря, visualViewport resize/scroll и изменениях DOM.
Полностью скрытый/удалённый якорь закрывает overlay. Если он исчез с фокусом внутри,
фокус возвращается в активный Dialog или корень страницы, не в удалённую кнопку.

Последний открытый overlay обрабатывает Escape раньше Dialog. Внешний клик закрывает
верхний overlay. Фоновые overlay не открываются поверх чужого модального окна.
При отсоединении дерева/переходе по истории слой закрывается, listeners/observers
освобождаются; повторное подключение восстанавливает связь с якорем.

Тесты проверяют поколения событий, отключённые пункты, сохранение ввода, очистку,
все стороны размещения, сдвинутый visualViewport, удаление якоря во время ответа,
реальный overflow/transform-контейнер, 320/1280 px, клавиатуру, touch и axe.
Уменьшение viewport в автоматическом тесте моделирует доступную область при экранной
клавиатуре; физическая клавиатура iOS/Android на облачном desktop не проверялась.
