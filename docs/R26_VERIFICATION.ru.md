# Проверка R26: даты, время и диапазон

Дата: 16 ноября 2026 года. База: `f0b98eaaeab603f260597334dce4bdf84a8e54e8`.
Ветка: `feat/date-time-fields`. Точный SHA реализации указан в PR;
публикуемое дерево сверяется с проверенным рабочим деревом.

## Среда и команды

Облачный Debian 13, Temurin JDK 21.0.13, Maven 3.9.9, Node.js 24.22.1,
Playwright 1.62.1. Использован установленный через npm ci набор из неизменённого
package-lock.json. Maven offline использует предварительно загруженный кэш.

- `mvn -o verify`: **619 Java-тестов**, ошибок и пропусков нет;
  Checkstyle — 0 замечаний; JAR, sources и JavaDoc собраны.
- `npm run check:js`: ESLint и Prettier проходят.
- `npm run test:js`: **249 тестов**, все проходят.
- `npm run check:gallery`: **57 конкретных классов / 75 изображений**;
  проверены ссылки, alt, размеры, границы вырезок и SHA-256.
- `node scripts/run-e2e.mjs temporal.spec.js`: **8/8** проходят,
  Chromium и WebKit, ru-RU/en-US, 390/1280 px.
- Полный `npm run test:browser`: **216/216 E2E**, 9,7 минуты; также прошли
  проверки JavaScript, модульные JS-тесты и проверка галереи.

После полного прогона добавлена только проверка null для имени DateRange
и Java regression assertion. На окончательном дереве повторены `mvn -o verify`
(619 тестов) и целевые 8 E2E; JavaScript и визуальное поведение не менялись.

Как в R24/R25, в локальной среде дополнительные библиотеки WebKit распакованы
из официальных Debian-пакетов. Браузеры получены из официальных дистрибутивов.
`PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1` отключает только проверку
системного ldconfig, не видящего локальные библиотеки. Реальные браузеры,
тесты и assertions запускаются; CI workflow и проверки не ослаблены.

## Проверенные сценарии

Java: високосное 29.02.2028 и неверное 29.02.2027; 31 апреля; строгий ISO-формат,
год 0000/10000, пустое и незавершённое значение; отсутствие устаревшей даты после
ошибки; включительные min/max, изменение границ без clamping, общая модель
двух полей; минутная точность, неверные часы/минуты, запрещённый диапазон через
полночь; формат ru/US; явная конверсия с DST-gap, двумя offset в overlap и
отказом для неверного смещения. Проверены пустой/частичный/обратный/однодневный
диапазон в Form, отсутствие вызова обработчика при ошибке, дубликаты имён,
владение полями и снятие подписок при dispose.

JS: каноническое значение без timezone-арифметики, отличие нативного badInput
от очистки, сохранение незавершённых сегментов при эхо сервера, применение
языка/границ без изменения ввода и отказ от некорректной конфигурации.
В тестовом окружении клиента добавлена заглушка нового обработчика протокола;
начальные падения из-за отсутствующей заглушки устранены, тесты не исключались.

E2E: native date/time и step=60; подписи/help/ошибки FormField, required и фокус
на первой ошибке, min/max, одинаковые границы, обратный и пустой диапазон,
отправка Enter/кнопкой, disabled, смена lang и серверного форматирования без
изменения значения. Все сценарии выполняются при timezone браузера
America/Los_Angeles: дата не сдвигается на предыдущий день. Мобильная отправка
использует tap; проверены ширина формы и axe для новых нативных редакторов.

## Облачный компьютер

Собранный AllWidgets запущен на облачном компьютере; проверены широкий экран
и iframe шириной 390 CSS px. Нативный календарь открыт реальным кликом,
выбран день 28 февраля; сервер принял именно 2028-02-28. Исправление обратного
диапазона привело к успешной отправке с одинаковыми границами. На мобильной
ширине подтверждены перенос подписей, ошибка времени 18:01, успешная граница
18:00 и отсутствие необязательного периода. Кнопка отправлена клавишей Enter.

Это не проверка физического Android/iOS; ручное прослушивание screen reader
не проводилось. Нативный Chromium показывает MM/DD/YYYY и AM/PM даже при lang=ru:
это зафиксированное ограничение платформенного редактора, описанное в API.

Четыре изображения вырезаны из настоящих облачных скриншотов без масштаба
и ретуши; календарь снят через нативный рабочий стол. Происхождение,
координаты, размеры, базовый commit и SHA-256 AllWidgets записаны в
[manifest.json](images/widgets/manifest.json). Все три новых виджета представлены
в [галерее](WIDGET_GALLERY.ru.md#temporal) и [документации API](TEMPORAL_FIELDS.ru.md).
