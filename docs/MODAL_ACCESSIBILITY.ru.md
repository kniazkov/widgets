# Доступность ModalPopup

`ModalPopup` представлен как диалог. Задайте понятное имя через
`setAccessibleName`, обычно такое же, как видимый заголовок, и при необходимости
краткое текстовое описание через `setAccessibleDescription`. Имя по умолчанию
`Dialog` сохраняет доступное имя для старого кода, но не объясняет назначение окна.

```java
final Button opener = new Button("Изменить адрес");
opener.onClick(event -> {
    final Button close = new Button("Закрыть");
    final ModalPopup dialog = new ModalPopup(new Section(new TextWidget("Адрес")),
        new Section(close));
    dialog.setAccessibleName("Адрес");
    dialog.setAccessibleDescription("Проверьте адрес перед отправкой.");
    dialog.setCloseOnEscape(true);
    close.onClick(click -> dialog.dispose());
    root.add(dialog);
});
```

- Начальный фокус получает первый доступный элемент в порядке Tab. Если их нет,
  фокусируется само окно. Tab и Shift+Tab циклически перемещают фокус внутри него.
- Действует только переднее видимое окно. Фоновые ветви становятся `inert`:
  они недоступны мыши, клавиатуре и вспомогательным технологиям. При вложении
  родительское окно остаётся в DOM, но его фоновые контролы исключаются.
- Escape и нажатие на фон включаются независимо (`setCloseOnEscape(true)` и
  `setCloseOnOutsideClick(true)`). Обе опции по умолчанию выключены; существующее
  поведение мыши и touch не меняется. Если Escape запрещён в верхнем окне, нижнее
  не закрывается. Вложенный контрол может обработать Escape раньше самого окна.
- Скрытие, скрытие контейнера, удаление и `dispose()` возвращают фокус к инициатору
  или к первому доступному контролу оставшегося диалога. Если инициатора и диалога
  больше нет, фокус возвращается к контейнеру страницы, не прокручивая её.
- По умолчанию у окна остаётся место для обводки фокуса по краям узкого viewport;
  явно заданные размеры приложения могут изменить этот отступ.
- Модальное поведение требует поддержки HTML `inert` в современном браузере.
  Обычный `Popup` не перехватывает фокус. Если отключены обе опции закрытия,
  приложение должно предоставить явное действие закрытия.
