# Типизированный выбор: Select, ComboBox и MultiSelect

Свяжите вариант со стабильным ключом и серверным значением. Подпись может
повторяться и меняться, а изменение порядка не меняет выбранные ключи. Ключ
должен однозначно обозначать одну сущность; значение `T` не передаётся в браузер.

```java
record Product(int id) {}
var paper = new ChoiceOption<>("product-17", "Бумага", new Product(17));
var other = new ChoiceOption<>("product-23", "Бумага", new Product(23));
var select = new Select<>(List.of(paper, other));
select.setAccessibleName("Товар");
select.setPlaceholder("Выберите товар");
select.onChoose(keys -> process(select.getSelectedValues()));
select.setOptions(List.of(other, paper)); // выбранный ключ сохранится при перестановке
```

- **Select** использует нативный выпадающий список. Пункт-подсказка сбрасывает
  выбор. **MultiSelect** использует нативный список множественного выбора:
  жесты выбора зависят от браузера/ОС. `clear()` очищает выбор; для явной
  кнопки сброса (особенно на touch) привяжите её к этому методу. Подсказка
  MultiSelect используется как дополнительный `title`, а не как вариант.
- `getSelectionModel()` принимает неизменяемый снимок ключей (входной список
  копируется) и публикует реактивные изменения. `getSelectedValues()` возвращает
  текущие значения соответствующих ключей в порядке модели. При замене опций
  отсутствующие или ставшие недоступными ключи удаляются. Неизвестный,
  недоступный или повторный ключ отклоняется; два одинаковых ключа в списке
  опций считаются ошибкой.
- **ComboBox** с `freeTextAllowed=false` считает текст только запросом:
  выбранное значение появляется после явного выбора существующего пункта.
  При закрытии возвращается подпись текущего выбранного ключа. В режиме
  `true` произвольный текст доступен отдельно через `getFreeText()`, а печать
  снимает выбранный ключ. Кнопка ×, или Ctrl+Delete при закрытом списке,
  очищает оба состояния. Стрелки активируют доступные варианты, Enter
  подтверждает активный, Escape закрывает, Tab не удерживает фокус. Обработка
  IME ждёт завершения композиции.
- Задавайте доступное имя или связь с видимой подписью. Нативные Select и
  MultiSelect выставляют обычные роли браузера; ComboBox использует
  `combobox`, связанный `listbox`, `aria-activedescendant` и
  `aria-selected`, а загрузка, пустой результат и ошибка видны и доступны
  через живой статус. Встроенные сообщения поиска сейчас на английском.
- В режиме поиска подсоедините `setProvider((query, cursor) -> future)`.
  Первый запрос получает пустой курсор, следующие страничные запросы —
  непрозрачное значение из `ComboBox.Page`; пустой следующий курсор
  завершает список. Возвращайте `CompletableFuture` быстро, не блокируя
  поток страницы. Новый запрос, явная отмена или утилизация вызывает
  `cancel(true)`; это лишь сигнал провайдеру. Запоздалый результат больше
  не меняет виджет. Ключи уникальны между страницами; накопленный снимок
  ограничен 512 вариантами, ключи 128, ввод 256 кодовыми единицами UTF-16.
  При фильтрации выбранный ключ сохраняется независимо от текущего окна
  результатов; для авторитетного изменения каталога вызовите `setOptions`.
- `DropDownList` и `SuggestionField` не меняют API и поведение.
  `FormField` по-прежнему принимает `InputField`; виджеты выбора не
  преобразуют типы в строки автоматически. Проверяйте семантику домена при
  прикладном сохранении и используйте `setValidState(false)` для сообщения
  о невалидном выборе.
