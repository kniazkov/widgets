# Подключение Widgets по частям

Для веб-приложения достаточно одной зависимости. Maven подтянет ядро вместе с браузерными ресурсами.

```xml
<dependency>
    <groupId>com.kniazkov</groupId>
    <artifactId>widgets-http</artifactId>
    <version>0.2.1</version>
</dependency>
```

| Артефакт | Содержимое | Требуется для подключения |
| --- | --- | --- |
| widgets-core | Модели, виджеты, состояние приложения, HTML/JS, базовые ImageSource | JSON и webserver. Публичный Options использует SslOptions, загрузка файлов использует таблицу MIME |
| widgets-http | HTTP, WebSocket, push и обработчики запросов | widgets-core, Jetty |
| widgets-db | Запросы, хранилища, JSON и JDBC persistence | widgets-core. JDBC-драйвер выбирает приложение |
| widgets-images | Загрузка, ограничение размеров и обработка изображений, HEIC, EXIF и ImageIO-провайдеры | widgets-core и библиотеки обработки изображений |
| widgets | Полная совместимая сборка с примерами, включая AllWidgets | Прежние координаты и полный набор runtime-зависимостей |

Используй либо полный JAR, либо компоненты одной версии. Полный JAR уже содержит классы всех компонентов. Все варианты рассчитаны на обычный Java classpath. Для минимального варианта добавляй widgets-db или widgets-images только при использовании соответствующего API.

Из корня репозитория:

```sh
mvn clean install                   # весь выпуск, включая полный JAR с примерами
mvn -f modules/pom.xml clean install # четыре компонента и родительский POM
mvn -f src/test/minimal/pom.xml verify
```

Минимальное приложение в `src/test/minimal` показывает публичную страницу и обрабатывает нажатие кнопки. Release candidate собирает его как внешнего Maven-потребителя, сравнивает состав и размер runtime classpath с полным потребителем и запускает обе страницы в Chromium. Проверка сравнивает классы четырёх модулей с полным выпуском и обнаруживает дублирование и пропуски. Все модули компилируются из тех же исходников, что и полный выпуск. Расширения содержат маркер для ReleaseInfo, чтобы идентификатор сборки учитывал каждый установленный модуль.
