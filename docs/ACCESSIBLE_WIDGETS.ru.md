# Семантика и доступные имена Widgets

Нативная семантика не меняется при назначении имени: кнопка остаётся кнопкой,
поле остаётся полем. Назначайте семантику интерактивным элементам и заголовкам,
не используйте `aria-label` как единственный текст обычного контейнера.

```java
final TextWidget title = new TextWidget("Доставка");
title.setHeadingLevel(HeadingLevel.H2);
final TextWidget label = new TextWidget("Код доставки");
final TextWidget help = new TextWidget("Четыре цифры.");
final TextWidget error = new TextWidget("Код заполнен не полностью.");
final InputField field = new InputField();
field.setAccessibleName("Код");         // Запасное имя, когда подписи нет в дереве.
field.setAccessibleLabel(label);
field.setAccessibleDescriptionWidget(help);
field.setAccessibleError(error);        // Передаётся только в состоянии invalid.
field.setValidState(false);
final Button refresh = Button.icon(new ImageWidget("/refresh.svg"), "Обновить");
final ImageWidget map = new ImageWidget("/map.svg");
map.setAlternativeText("Склад находится к северу от станции.");
```

Добавьте связанные виджеты в ту же страницу. Видимый текст подписи важнее
явного имени; после переименования имя обновится без переназначения связи.
Отсоединение скрывает ссылку, повторное присоединение восстанавливает её,
а окончательное уничтожение очищает. Передайте `null`, чтобы сбросить связь.
Пустое явное имя возвращает нативное имя элемента, например текст кнопки.
`setAccessibleDescription` задаёт текст, а связанный help имеет приоритет
у обычного элемента. Модальное окно сохраняет текстовое описание и добавляет
связанный help к нему. `aria-errormessage` не передаётся для валидного поля;
активная ошибка также входит в описание для вспомогательных технологий без
поддержки `aria-errormessage`. Показ сообщения на экране и его локализация
остаются задачей приложения.

`HeadingLevel.H1…H6` меняет только семантику заголовка, а `PLAIN` возвращает
обычный текст. Информативным изображениям укажите alt; пустой alt остаётся
пустым. `setDecorative(true)` исключает картинку из дерева, сохраняя её
alt в модели для последующего возврата. `Button.icon` создаёт обычную кнопку
с собственным обязательным именем и декоративной картинкой; он не требует
отдельного класса или обработчиков клавиатуры. Для нового действия с изображением
предпочтите этот вариант, а не старый указательный `ActiveImage`.

Текст имени, описания и alt передаётся как данные, а не HTML. Перед публикацией
страницы всё равно проверяйте дерево доступности и порядок клавиатуры: наличие
семантического API не назначает имена существующим контролам автоматически.

## Что ещё не проверено или не исправлено

Проверка axe всей страницы AllWidgets в Chromium и WebKit всё ещё обнаруживает
контраст старых примеров, поля и списки без явных имён, слайды Carousel без
текстовых альтернатив и отсутствие общей разметки landmark/main. Последнее
затрагивает и размещение нового раздела на странице. Проверка самих новых
контролов, изображения и связанного поля нарушений не нашла; это не сертификат
доступности всей галереи. Сценарии touch прогнаны автоматически; ручная проверка
в облачном браузере покрывает мышь, клавиатуру и узкий экран, а не физический touch.
