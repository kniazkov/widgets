# Проверка R25: типизированные диалоги

Дата: 16 ноября 2026 года. База: `2407eb4c70897ff91726cb3e9f7a1dd01ca20cb9`.
Проверена рабочая ветка `feat/dialog-results`; точный SHA реализации указан в PR.

## Среда

Облачный Linux Debian 13, Temurin JDK 21.0.13, Maven 3.9.9,
Node.js 24.22.1, Playwright 1.62.1. Использован установленный через `npm ci`
набор зависимостей из lock-файла. Maven работает offline после загрузки зависимостей.
Локальные библиотеки WebKit распакованы из официальных Debian-пакетов;
браузеры получены из официальных дистрибутивов Playwright/Chrome for Testing.
Как в R24, `PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1` отключает только
проверку системного ldconfig, который не видит локальные библиотеки.
Оба браузера действительно запускаются, тесты и assertions не отключены.
CI использует штатную установку библиотек; workflow не изменён.

## Выполненные проверки

- `mvn -o verify`: 613 Java-тестов без ошибок, Checkstyle — 0 замечаний,
  собраны JAR, sources и JavaDoc. Предупреждения JavaDoc
  не скрывались и не превращались в исключения из проверки.
- `npm run check:js`: ESLint и Prettier.
- `npm run test:js`: 247 тестов без ошибок.
- `npm run check:gallery`: 54 класса, 71 изображение; проверены наличие,
  Markdown/alt, SHA-256, размеры и границы вырезок.
- Полный `npm run test:browser`: все этапы прошли; **208 E2E-тестов**
  успешно завершились за 8,7 минуты (Chromium и WebKit), без пропусков и падений.

Java-сценарии: ровно один confirm/cancel/close, невозможность завершить результат
через внешнюю копию future, двойной submit, серверный запрет dismiss при busy,
обязательное поле и прикладной validator, неизменяемый снимок полей, свежие данные
при повторе, синхронное исключение и null-результат, безопасный текст ошибки,
позднее завершение после disposal, вложенный диалог при закрытии страницы.

JS-сценарий проверяет resize/scroll visualViewport, снятие обработчиков при
удалении и повторное присоединение без дублирования backdrop.

Десять новых E2E-сценариев выполняются в Chromium и WebKit: 1280/390 px,
валидация по Enter, двойной Enter и double-click, busy с заблокированными
кнопками/Escape/outside-click, ошибка и повтор с сохранёнными данными,
различимые исходы закрытия, вложенность и возврат фокуса. axe проверяет
диалог подтверждения. Проверка длинной кнопки воспроизводит найденное
при визуальном просмотре переполнение подписи на мобильной ширине.

Экранная клавиатура проверяется автоматизированной моделью visualViewport
390×300 со смещением offsetTop=100: Tab проходит по длинной форме, фокус
остаётся внутри видимой части окна, содержимое прокручивается. Это проверка
viewport-логики, не испытание физической клавиатуры iOS/Android.

## Облачный браузер и изображения

Собранный AllWidgets запущен на облачном компьютере и открыт через Chromium:
широкий экран и iframe 390×870 CSS px. Мышью открыты подтверждение и форма;
после отказа серверного действия значение «Бумага» сохранено, Enter повторяет
операцию до `CONFIRMED`. Вложенный диалог закрывается Escape и возвращает фокус
на кнопку родителя. Перенос длинной кнопки исправлен и повторно проверен
визуально на окончательной сборке. Touch проверен E2E через `tap()`.
Ручное прослушивание screen reader не проводилось.

Три PNG вырезаны из настоящих скриншотов без изменения масштаба/ретуши:
подтверждение, ошибка с сохранённой формой, длинная форма на мобильной ширине.
Исходные размеры, координаты, базовый SHA и SHA-256 AllWidgets записаны в
[manifest.json](images/widgets/manifest.json). Снимки подключены в
[галерею](WIDGET_GALLERY.ru.md#dialog), контракт — в [DIALOGS.ru.md](DIALOGS.ru.md).
