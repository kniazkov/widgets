# Проверка R31

База: `2ab701205a7be01d7e356fe6a76b0138e73b2392` (после PR #182).
Исходная реализация: `91a4a8b166e427c4ac9c693d90b8575c54904308`.

Локальные команды в рабочем облачном окружении:

- `mvn verify`: 643 Java-теста, ошибок нет; Java 21, Maven 3.9.9.
- `npm run check:js`: ESLint и Prettier прошли.
- `npm run test:js`: после дополнительной проверки отсоединения композиции — 279 тестов.
- `npm run check:gallery`: 67 классов, 92 изображения. Новых визуальных компонентов нет.

CI исходной реализации: [44046227073](https://github.com/kniazkov/widgets/actions/runs/44046227073).
Обе Java-сборки (Linux/Windows) прошли. Полный браузерный результат и итоговую ревизию
следует смотреть в [проверках PR #183](https://github.com/kniazkov/widgets/pull/183/checks).
До их завершения браузерная приёмка не считается успешной.

Браузерные тесты используют реальный HTTP-сервер, Chromium и WebKit. Проверяются
немедленные focus/selection при задержанной отправке запросов, отказ бизнес-команды,
быстрый ввод, порядок text input → Enter, сохранение каретки, отложенная нормализация,
compositionend + повторяющийся input, открытие новой вкладки и отсутствие opener.
В JS-тестах также проверяется отмена активной композиции при отсоединении обычного
поля и SuggestionField, без отправки незавершённого текста и блокировки последующего ввода.

CompositionEvent/InputEvent в автоматическом тесте синтетические. Нативный системный
IME/виртуальная клавиатура не проверены и не отмечены как выполненная ручная приёмка.
Ограничения popup blocker и пример ручной проверки описаны в LOCAL_ACTIONS_IME.ru.md.
