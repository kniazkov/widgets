# Подписки на клавиатуру в текстовых редакторах

`InputField`, `PasswordInput`, `SuggestionField` и `TextArea` принимают
точечные подписки. Другие виджеты сохраняют обычное поведение: например, кнопка
пользуется нативной активацией, а выбор, карусель и окно оставляют свои
специализированные команды. Контейнер не перехватывает нажатия дочернего редактора.

```java
InputField user = new InputField();
PasswordInput code = new PasswordInput();
Button submit = new Button("Apply");
Runnable attempt = () -> validateDemoInput(user.getText(), code.getText());
user.onEnter(event -> attempt.run());
code.onEnter(event -> attempt.run());
submit.onClick(event -> attempt.run());
```

Этот вызов использует одну серверную проверку для кнопки и Enter. AllWidgets
содержит **Keyboard login demo** с вымышленными данными, а не авторизацией.
Пример не записывает значения полей в результат, сообщения о клавишах или логи.
Обычное событие ввода, которое обновляет модель поля, остаётся отдельным.

- `onEnter` регистрирует только нажатие Enter без модификаторов, включая
  NumpadEnter. Удержание не повторяет действие. Второе нажатие запускает
  второе действие. Не привязывайте тот же submit к отпусканию клавиши.
- `onKeyDown(shortcut, preventDefault, controller)` и
  `onKeyUp(shortcut, controller)` наблюдают явно указанные физические фазы.
  `KeyboardEvent.Shortcut` содержит именованную клавишу и точный набор
  Ctrl/Alt/Shift/Meta. Поддерживаются Enter, Escape, стрелки, Home/End и
  PageUp/PageDown. Печатные клавиши и Tab не отправляются.
- `TextArea` сохраняет обычный перевод строки. Для действия назначьте отдельную
  комбинацию, например Ctrl+Enter, через `onKeyDown`. По умолчанию
  модифицированный Enter не равен простому Enter.
- При `preventDefault=true` действие браузера и всплытие отменяются синхронно
  на целевом поле, не по ответу сервера; для необъявленных сочетаний отмены нет.
  Сначала работают локальные правила редактора. Например, Enter при открытом
  списке подсказок не отправляет submit, даже если вариант не выделен.
  Подтверждение IME и автоповтор не отправляют событие.
- `setReadOnly(true)` оставляет поле фокусируемым, но запрещает редактирование и
  клавиатурные действия. Disabled, скрытый, удалённый или чужой адресат не
  выполняет действие. `null` вместо callback удаляет конкретную подписку.
  Подписки ограничены 32 сочетаниями с фазой на редактор. Временное снятие
  и восстановление не удваивают listeners; disposal освобождает подписки.

## Порядок и совместимость

Обычный `input` попадает в существующую упорядоченную очередь до события
клавиатуры. Сервер применяет текст к модели до обработчика Enter, даже пока поле
в фокусе и пока сеть доставляет более ранние события. Отдельного сетевого пути
для submit нет. Повтор пакета с уже обработанным ID не повторяет callback.
Клавиатурный payload состоит только из разрешённых `key`, `phase` и четырёх
логических модификаторов; данные поля, raw key code или текст композиции в него
не попадают. Сервер независимо сверяет подписку и живой адресат.

API добавляется без изменений поведения несубскрибированных приложений; новые
опциональные настройки требуют браузерный runtime той же сборки. R20 использует
эту последовательность для формы, а не добавляет параллельный способ отправки.
IME проверяется моделированием событий; эмуляция не заменяет физический IME или
экранную клавиатуру мобильного устройства.
