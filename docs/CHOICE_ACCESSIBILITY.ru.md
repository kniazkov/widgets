# Доступные CheckBox и RadioButton

`CheckBox` и `RadioButton` теперь отрисовываются как нативные поля
`input[type=checkbox]` и `input[type=radio]`. Изображения из стилей, размеры, цвета,
реактивные модели `checked`/`disabled` и серверное событие `check` сохраняются.
Не привязывайтесь к тегу `img` при поиске этих виджетов: используйте их роль и имя.

- **Tab / Shift+Tab** переходят между доступными полями. У группы радиокнопок это
  обычно выбранное поле либо первое доступное поле, если выбора нет.
- **Space** переключает чекбокс или выбирает радио; выбранное радио повторным нажатием
  не сбрасывается. **Стрелки** меняют выбор в `RadioGroup` по кругу и пропускают отключённые поля.
- `CheckBoxWithText` и `RadioButtonWithText` связывают видимую подпись с полем через
  `label`. Клик или касание подписи активирует поле один раз. `getTextWidget()`
  по-прежнему настраивает текст, но его серверный клик больше не переключает модель.
- Синий контур показывает клавиатурный фокус. В режиме принудительных цветов браузер
  рисует нативный индикатор вместо SVG. У этих контролов нет состояний loading/invalid.

Для нового виджета с видимой подписью предпочтительна подписанная форма.
Для самостоятельного поля задайте конкретное, локализованное доступное имя вместо
общего имени «Checkbox» или «Radio button»:

```java
final CheckBox notifications = new CheckBox();
notifications.setAccessibleName("Уведомления о доставке");

final RadioButtonWithText delivery = new RadioButtonWithText("Доставка");
final RadioButtonWithText pickup = new RadioButtonWithText("Самовывоз");
new RadioGroup(delivery.getRadioButton(), pickup.getRadioButton());
delivery.check();
```

Имя можно привязать к модели через `setAccessibleNameModel`. Если у подписанного
поля явно задано отдельное имя, оно имеет приоритет над видимой подписью; обычно
это не требуется. При пересечении нескольких `RadioGroup` серверные модели
сохраняют прежнюю семантику; нативные стрелки работают в первой назначенной группе.
Обычный случай: одна группа на радиокнопку. `group.remove(button)` возвращает полю
самостоятельный Tab-стоп, если оно больше не состоит в группе.
