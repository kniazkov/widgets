# TreeView

Дерево для выбора одного объекта по стабильному строковому ключу. При создании передай список корней, функцию загрузки непосредственных детей и подписи трёх состояний. Пример с одной веткой и одним листом:

```java
TreeView tree = new TreeView(
    List.of(new TreeView.Node("glass", "Витражное стекло", true)),
    key -> CompletableFuture.completedFuture(List.of(
        new TreeView.Node("pendants", "Подвески", false))),
    new TreeView.Messages("Загрузка…", "Пока пусто", "Ошибка загрузки"));
tree.setAccessibleName("Категории украшений");
root.add(tree);
```

**Загрузка.** Первое раскрытие вызывает provider в потоке страницы. Для ввода-вывода верни `CompletionStage<List<TreeView.Node>>` сразу и выполни работу асинхронно. Виджет сам доставит результат в контекст страницы. Каждый ключ уникален во всём дереве. Дубликат внутри ответа или ссылка на существующий узел, включая предка, переводит ветку в состояние ошибки. Результат принимается целиком. Ошибочную ветку можно закрыть и раскрыть повторно.

**Состояние.** Модели `getSelectedKeyModel()` и `getExpandedKeysModel()` доступны для чтения и подписки. Для изменения используй `select`, `expand` и `collapse` в контексте страницы. Программное раскрытие требует смонтированного виджета. Пустая строка снимает выбор. Сворачивание закрывает вложенные раскрытые ветки и сохраняет выбор и успешно загруженных детей. Запоздавший ответ после сворачивания, удаления или повторного запроса игнорируется.

**Изменения данных.** `rename(key, label)` обновляет подпись. `move(key, parentKey)` переносит узел со всем поддеревом в конец уже загруженной ветки. Пустой ключ назначения возвращает узел на верхний уровень. Выбор следует за ключом при переименовании и переносе. `remove(key)` удаляет всё поддерево и снимает выбор, если выбранный узел входил в него. Изменения внешнего источника приложение отражает вызовами этих методов.

**Управление.** Tab переводит фокус на дерево. ↑ и ↓ перемещаются по видимым узлам, Home и End переходят к первому и последнему. → раскрывает ветку или переходит к первому ребёнку, ← сворачивает ветку или переходит к родителю. Enter и пробел выбирают узел. Мышью и касанием нажми треугольник для раскрытия или подпись для выбора. После удаления активного узла фокус переходит к видимому предку либо ближайшему соседу.

**Размер.** Виджет хранит посещённые узлы, передаёт и рисует видимые строки. Один ответ provider содержит всех непосредственных детей ветки. Постраничной загрузки и виртуализации внутри раскрытой ветки нет. В тесте дерева из 1 111 111 потенциальных узлов раскрытие пути глубиной шесть вызвало загрузку 60 детей. С корнем браузер получил 61 строку.
