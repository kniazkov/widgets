# Предварительная базовая линия R33

Облачная рабочая машина, 17 ноября 2026. База `3eb32dd287730b8225d9b891802b9262a1a31916`
с незакоммиченными изменениями R33. Это диагностический замер разработки, не SHA
готового PR. После него уточнено последовательное удаление страниц внутри истории,
чтобы вложенный pool не превышал concurrency; CI артефакт фиксирует итоговый код.

AMD EPYC 9V74, 9 видимых CPU, RAM 10 451 427 328 байт, Linux 6.18.57;
OpenJDK 21.0.13+9 Debian, Node 24.22.1, JVM `-Xmx1g`. Браузер **не запускался**.
Команда: `JAVA_HOME=/tmp/cpg-jdk node scripts/run-load.mjs --clients=1,100,1000 --repeats=2 --output=target/load-local`.
36 фаз прошли, сумма длительности 195,52 с. После каждой фазы страницы, виджеты,
очереди и активные загрузки вернулись к нулю. Сборка: `mvn verify`, 649 Java-тестов;
JS: 283 теста. Методика и ограничения — [LOAD_TESTING.ru.md](LOAD_TESTING.ru.md).
