# DataTable и DataProvider

`DataTable` показывает ограниченную страницу из асинхронного `DataProvider`.
Существующие контейнеры `Table`, `Row` и `Cell` остаются без изменений.

```java
var columns = List.of(
    new DataTable.DataColumn("reference", "Номер заказа", true),
    new DataTable.DataColumn("status", "Статус", false));
var table = new DataTable("Закрытые заказы", columns, 20, query ->
    orders.findAsync(query.filter(), query.sortKey(), query.descending(),
                     query.offset(), query.size())
          .thenApply(result -> new DataProvider.Page(result.rows(), result.matchCount())));
table.onSelect(keys -> selectionChanged(keys));
```

Первая страница запрашивается при появлении таблицы в видимой области.
Чтобы загрузить её заранее, вызовите `reload()` после присоединения.

- Строка `DataProvider.DataRow(key, cells)` содержит стабильный ключ и
  отображаемый текст по ключам колонок. Ключ строки обозначает одну и ту же
  запись при фильтрации, сортировке и перелистывании. Заголовок колонки
  не заменяет ключ сортировки. Ключи и текст передаются браузеру; не
  помещайте в них скрытые данные.
- Provider сам фильтрует, сортирует и выбирает страницу. Возвращайте не
  больше запрошенного количества строк и общее число совпадений до
  пагинации. Номер страницы начинается с нуля; offset имеет тип `long`.
  Пустой фильтр означает нефильтрованный список приложения.
- Не блокируйте поток страницы: быстро возвращайте `CompletableFuture`.
  При новом запросе и утилизации вызывается `cancel(true)`; даже если
  отменить работу невозможно, устаревший результат не применяется.
  Загрузка оставляет предыдущий список с `aria-busy`. Ошибка сохраняет
  последние строки, показывает общее сообщение и кнопку повтора.
  Успешный пустой ответ показывает «нет результатов», не удаляя архив.
- Выбор сохраняется при перелистывании, фильтрации и перестановке.
  `getSelectedKeys()` и `onSelect` передают неизменяемые снимки,
  `clearSelection()` сбрасывает выбор. `updateRow` заменяет видимую
  запись с тем же ключом без перестановки. `removeRow` снимает выбор
  действительно удалённой записи, даже если она скрыта. Сначала измените
  хранилище, затем `reload` для заполнения страницы. Неудалённый ключ
  сохраняет DOM-строку и фокус; если строка исчезает, фокус возвращается
  в фильтр.
- В браузере это нативные `table`, `caption`, `th scope=col`,
  `aria-sort` на сортируемом заголовке и именованные чекбоксы. Tab
  переходит между фильтром, областью прокрутки и элементами управления;
  Space выбирает строку; Enter/Space сортирует. В узком окне прокручивается
  только область таблицы, а не вся страница. `DataTable.Messages` задаёт
  язык сообщений, приложение задаёт подписи колонок и текст ячеек.
- До 32 строк на странице и восьми колонок, 160 кодовых единиц UTF-16
  на текст ячейки, 96 на ключ, 120 на фильтр, 512 выбранных ключей.
  Произвольные дочерние виджеты, автоматическая запись данных и
  виртуализация не предусмотрены. См. [живой пример](WIDGET_GALLERY.ru.md#data-table).

Область строк имеет постоянную высоту `20rem` и внутреннюю прокрутку: загрузка и смена страниц не сдвигают элементы ниже таблицы. Высоту можно изменить CSS-переменной `--widgets-data-table-height`. Место под строку состояния резервируется и при отсутствии сообщения.
